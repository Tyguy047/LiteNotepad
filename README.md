# Notepad

![Logo & Icon](assets/images/icon.png)

#### A GUI text editor that is minimal by design.

## User Guide
- Ctrl + S: Save
- Ctrl + O: Load
- Ctrl + W: Close File
- Ctrl + Q: Exit Notepad
- Ctrl + Z: Undo
- Ctrl + Shift + Z: Redo
- Ctrl + F: Change Font
- Ctrl + Shift + F: Change Font Size
